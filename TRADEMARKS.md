# The name and the mark

Anyone may implement the UFO format, for any purpose, without asking. The
licences in this repository grant that, and nothing here takes it back.

What is reserved is the meaning of the name. "UFO", "Universal File
Object" and the flying-saucer mark 🛸, used as the name or badge of a
reader, writer or other implementation, are reserved for implementations
that pass the project's conformance suite, so that "reads UFO" tells a
person something they can rely on.

- You may always say, truthfully, that your software reads, writes or works
  with UFO files, and use the `.ufx` ending and the `application/vnd.ufx`
  media type. That is description, not use of the mark.
- You may use the name and the mark for an implementation once it passes
  the conformance suite for the version of the specification it claims.
- You may not use them in a way that suggests an implementation passes
  when it does not, or that the project endorses a product.

The conformance suite does not exist yet. Until it does, nothing can
qualify, and the name should be used descriptively only.

No registration of the name or the mark is claimed here. The licences that
cover the code, the vectors and the specification grant no trademark
rights ([LICENSE](LICENSE), section 6; [SPEC-LICENSE.md](SPEC-LICENSE.md),
section 4). This policy will be reviewed by counsel before the project's
public launch.
